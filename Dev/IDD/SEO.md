Search engine optimization for a startup page is mostly hygiene: the page must be indexable, fast, and clearly about one thing. Do the mechanics before you tune the copy:

1. Give the page one primary topic and a matching title, and a description that would make a stranger click.
2. Use a single H1 that states the topic; the rest are subheadings.
3. Keep pages small and link to the detail instead of stuffing one page with everything.
4. Provide a sitemap and a robots file, and fix broken links when a checker finds them.
5. Measure what you actually serve, not an assumed ranking. Ranking is a lagging result of the page being useful, not a goal you set directly.

This page lists the baseline; the working procedure for auditing a specific site is not written yet.
