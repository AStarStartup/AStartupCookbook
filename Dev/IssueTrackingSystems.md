This section is going to primarily focus on the GitHub Issue-tracking system.

This section covers GitHub issue tracking as the working system. An issue is a unit of work with a problem, a proposed solution, the files it touches, and an acceptance check; a mission ticket is an issue that also drives a branch and a commit sequence. The working conventions are described in the [Agentic Driven Development](./IDD/README.md) pages, including how the commit letter must match the ticket section. This page is a stub until it carries its own procedure for choosing and sizing issues rather than only pointing at the method.
