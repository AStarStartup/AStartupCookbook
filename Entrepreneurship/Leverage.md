Leverage is doing the work that multiplies instead of the work that only adds. The classic lever is a system or a product that keeps producing output after the founder stops working on it, against a task that must be redone every time. The test: if the founder is not in the room, does the thing still produce? If yes, it is leverage; if no, it is labor, and it should be scheduled like labor. This page is a stub until it names the specific levers a solo founder should build first.
