A formal argument is a statement that can be checked for validity: given the premises, does the conclusion follow? The working use in a startup is to separate the arguments that are valid from the ones that are only persuasive, because the founder will be asked to act on both. The minimum working form names the premises, the conclusion, and the rule that connects them, and then checks whether the premises are actually true, which is a separate question from whether the logic holds. This page is a stub until it carries a worked example of a startup argument checked that way.
