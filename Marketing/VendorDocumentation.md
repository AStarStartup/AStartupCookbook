Vendor documentation is the record a customer or a partner needs to use what you sell, written for the person using it under pressure. It covers what the product does, how to set it up, how to use it for the main tasks, and what to do when it fails. It is not the marketing copy; it is the thing the customer checks when the marketing has stopped being useful. This page is a stub until it names the minimum document set a first product needs before it is sold.
